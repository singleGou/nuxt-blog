# 脑屿模型

模型采用 HRA 的 **Brain, Male v1.3**，作者 Kristen Browne、Heidi Schlehlein（2023），CC BY 4.0。官方入口及 DOI、模型校验值见 `public/models/brain/provenance.json`，页面和 `NOTICE.txt` 均提供署名。

源数据来自 Allen 图谱，原作者通过镜像组成完整脑部。保留左右半球、小脑、脑干及原有脑沟、脑回；这不是某个个体左右半球的独立扫描。模型源文件的全部 283 个网格和名称均保留。

## 本地资源

- `public/models/brain/brain.glb`：本地提供，用户访问不依赖 NIH/HRA 网站。
- `scripts/prepare-brain-model.mjs`：Node 22 运行，可传入已下载的原始 GLB，也可以从官方源下载。固定源文件 SHA-256；源更新后需重新检查。
- 使用 glTF 标准的 `KHR_mesh_quantization`，只量化坐标、法线并统一调整材质，不做重建、不切割脑回、不减少三角面。
- 模型约 8.1 MB，仅在脑屿页面挂载后请求；有加载进度、超时重试和离页取消。

## 头部外形参照

新增 `public/models/head/head.glb`，从同一 HRA 的 **Skin, Male v1.2**（CC BY 4.0）提取头部和上颈部，约 252 KB；额头、鼻子、下颌和颈部提供方向参照。来源和署名见该目录的 `NOTICE.txt`、`provenance.json`。这是皮肤外形，未展示颅骨或头部的其他组织。

`scripts/prepare-head-model.mjs [cached-VH_M_Skin.glb]` 可重新生成。脚本在原始世界坐标 Y=0.685 米处裁切网格，并对跨平面的三角面做插值裁切，颈部切口不封盖。只使用大脑处理记录中的中心和平移比例，两者沿用同一套 HRA 坐标；不能单独将头部归一化或拉伸来拟合大脑。

`utils/headModel.ts` 创建透明头部材质，以视线与表面法线的夹角增强外轮廓，不绘制三角网格线。头部不加入脑区拾取列表，允许透过头部选择大脑。默认显示，可用“头部轮廓”开关隐藏；海马透视时进一步淡化外壳。头部资源失败时仍展示大脑，并提供明确的重新加载入口。

相机根据头部/大脑包围盒、观察方向、视口宽高比和视场角自动取景，并以对应包围盒中心为旋转目标。切换轮廓或调整窗口宽度会重新取景，避免头部在窄屏下裁切。

## 分组与交互

`utils/brainModel.ts` 按原始网格名称分组，不按空间坐标切色。前额叶入口选用额上回、额中回、额下回三角部和眶额脑回；这些脑回范围与前额叶不完全相同，页面明确提示，不将其声称为精确功能分区。运动皮层的中央前回不归入这一入口。顶叶、颞叶、枕叶也以原始脑回为探索分组，并非完整临床分割。

海马由原始头、体、尾六个网格构成（左右各三）。小脑使用原始蚓部、旁蚓部及小脑半球。其余皮层、白质和脑干用于外形参照；未介绍的深部核团、脑室等保留在文件里，界面隐藏，避免误选和视觉干扰。

默认不选择脑区，先展示完整脑外形。选择后局部着色，选择海马自动透视。提供左侧、右侧、正面、复位及随相机变化的方向标记；透明组织不阻挡海马点击，不透明但未分组的组织仍阻挡穿透选择。
